reviewed source and pure in-memory public-codec evidence for three producer/
pressure schedules. The [manifest](manifest.json) binds archive identity and all
29 current module hashes. `INVENTORY.json` records every other member's size and
SHA-256; members are regular UTF-8 files with safe relative paths.

The archive preserves the pushed 27-module B5d baseline, current and failed-test
snapshots, initial selection-only RED, all intermediate peer/test failures,
36 current normal/optimized command receipts, immutable references, source
review and Root audits. Each new-suite mode has five positive executions and
44 synthetic sensitivity controls. No whole producer response is retained.

Exact J/C/R is 9/8/64, 8/7/33 and 6/5/33; each hash-only producer response is
16777313 bytes. Four new body records and retained parsed output/binding facts
survive fresh contexts and final 67-status-plus-metrics collection. Source
coverage is 34/40; six selections remain unsupported before effects.

The identity audit distinguishes 119 retained rows from 114 unique entries,
and checks all 42 ordered codec files. Commands and pinned Python/model/core/
helper identities are in the archived implementation report. Source/licenses
are included; native binaries/cache are excluded. Supplied records do not
prove callback, native fixture, runtime or post-deinit behavior. Full40/default/
aggregate/native acceptance, project gates and adoption remain open. See the
[focused report](../../m2_h2_combined_producer_pressure.md).
