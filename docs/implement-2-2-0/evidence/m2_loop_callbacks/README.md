# Reviewed typed loop-callback adapter

The [archive](typed-loop-callbacks.tar.gz) preserves two exact source overlays
over prepared App/R2, preimages, complete source audits, raw verification,
observer IR and independent review. Reconstruction is described in SCOPE.md.

SHA256: `c617de4856580f23763d101692100e2547ad9bc39bd62e26700a7e98acb8ab20`
(7,747,617 bytes). The [manifest](manifest.json) binds 74 safe regular members,
73 inventory entries and omitted derived binaries by hash/size. Retained bytes
passed credential checks. Completed ELF outputs were moved to `/tmp` behind
identity-preserving symlinks to conserve workspace space; source is unchanged.

The actual pure ACK classifier preserves expected backend outcomes and exact
unexpected errors. Retain leaves an existing target pin unchanged; no result
permits physical close. The handle enforces its existing owner/fence invariant.
Typed cancellation, retirement and close failures set the existing latch before
a fixed panic. No new state, layout, arbitrary callback or root export is added.

Independent review finds no actionable findings. Pure tests pass 3/3 and
unchanged body-app tests 14/14 in Debug and ReleaseSafe. The earlier declaration,
comptime and backend-expectation failures remain distinct from behavioral policy
red/green. Healthy execution covers io_uring. Broader core, observer, Windows and
macOS checks compile or generate code only; fatal observers never execute.

All 905 base files, the 93-file immutable local libxev export and four root pin
views remain unchanged. Every compiler command uses the explicit reviewed
`c223bd886c6a51d2cd60def39dd9a68d701fea73` test override. This is not adoption.
The complete dependency source/history is saved in the
[registration-rollback archive](../m3_libxev_registration_rollback/README.md).

No native fault, cancellation, timing, race or leak probe ran. R3 V6 remains
unaccepted; no TCP/storage/App lifecycle or upload activation is implemented.
Future combined integration must preserve root timer fix `3cc8f81` and its
central regression rather than replacing current test source wholesale.
